# Data

Place sample images in:

```text
data/sample_images/
```

For BSDS500-style evaluation, use the following structure:

```text
BSDS500_processed/
├── images/test/
└── ground_truth/test/
```

Ground-truth labels can be named either:

```text
image_name_1.png
image_name_2.png
...
```

or:

```text
image_name.png
```

Large benchmark datasets are not redistributed in this repository. Please download them from their official sources.
